DentalCAD design docs
Reference For: engineers new to dentistry, dental experts new to the code

Glossary

Dental terms for engineers, and engineering terms for dental experts.

Teeth and directions

FDI notation
Two-digit tooth numbers: the first digit is the quadrant (1 upper right, 2 upper left, 3 lower left, 4 lower right), the second is the position from the midline (1 central incisor … 8 third molar). Tooth 36 is the lower-left first molar. Schema: Fdi.
Posterior teeth
Premolars (positions 4–5) and molars (6–8). The MVP's scope. isPosterior()
Anterior teeth
Incisors and canines (positions 1–3). Out of MVP scope.
Mesial / distal
Toward / away from the midline of the dental arch, along the arch. The "MD" axis in the tooth frame.
Buccal / lingual (palatal)
Toward the cheek / toward the tongue (palate in the upper jaw). The "BL" axis.
Occlusal / cervical
Toward the biting surface / toward the gum line (the tooth's "neck").
Proximal
The surfaces facing neighbouring teeth (mesial and distal).
Antagonist
The opposing tooth or teeth in the other jaw that the crown bites against.
Occlusion
How upper and lower teeth meet. Scans are assumed to arrive "in occlusion", already aligned to each other.
Gingiva / sulcus
The gum / the small groove between gum and tooth. The margin tool must not snap into the sulcus.
Cusp
A raised point on the chewing surface. Adapt-to-antagonist must preserve cusps (it smooths displacements, not positions).

Restorations and design

Crown (anatomic)
A full cap over a prepared tooth, shaped like a natural tooth. The MVP's only restoration type (anatomic-crown).
Prep (preparation)
A tooth ground down by the dentist to receive a crown. Its scan is the main input.
Margin line
The closed curve on the prep where the crown ends. The most precision-critical line in the design. Schema: MarginLine (anchors + dense points).
Chamfer / shoulder
Shapes of the prep's edge at the margin. A chamfer is a rounded bevel, a shoulder a flat ledge.
Insertion axis (path of insertion)
The direction the crown slides onto the prep. Must be free of undercuts. Schema: InsertionAxis.
Undercut
Part of the prep hidden when viewed along the insertion axis. A rigid crown can't pass it, so it is "blocked out" (filled) in the intaglio.
Blockout
Filling undercuts in the inner surface so the crown can seat.
Intaglio
The crown's inner (fitting) surface, which sits on the prep with a cement gap.
Cement gap
Space between prep and intaglio for the cement, typically 0.03–0.05 mm. Ramps from 0 at the margin. cementGapMm
Extra spacer
Additional gap applied beyond "distance to margin" to ease seating. extraSpacerMm, distanceToMarginMm
Margin thickness / minimum thickness
Material thickness at the margin, and the material's required minimum elsewhere (e.g. 0.5 mm zirconia, 1.0 mm lithium disilicate in the presets). MATERIAL_PRESETS
Occlusal clearance
Gap between crown and antagonist. The target is slightly positive (e.g. 0.05 mm); negative means intentional contact.
Contact point
Where the crown touches a neighbour. Too loose traps food; too tight won't seat.
Emergence profile
How the crown's surface leaves the gum line. Adapt-to-neighbours avoids the lower third to protect it.
Library tooth / template
A pre-made tooth shape fitted onto the margin as a starting proposal. The MVP uses 8 annotated templates.
Cervical loop
The open bottom edge of a template's outer shell, matched to the margin when fitting.
Coping / cutback
A thin substructure / a reduced crown for layering porcelain. Post-MVP.
Bridge / pontic / connector
A multi-unit restoration / its replacement tooth / the joint between units. Post-MVP.
Inlay / onlay / veneer
Partial restorations. Post-MVP.
Abutment / Ti-base / scan body
Implant parts: the connector above the implant / a titanium base / a scanned marker that locates the implant. Post-MVP.
Wax-up
A trial shape (physical or digital). "Copy mode" reuses it. Post-MVP.
Virtual articulator
Simulates jaw movement for dynamic occlusion. Out of scope.
Unmillable region
Concave detail smaller than the milling tool's radius; the mill can't reproduce it. Shown as a map; compensation is left to CAM.

Materials, devices and products

Zirconia
Strong ceramic for crowns; thinner minimums. Preset zirconia.
Lithium disilicate (e.max)
Glass-ceramic with high aesthetics; thicker minimums. Preset lithium-disilicate.
PMMA
Acrylic, used for temporary crowns. Preset pmma.
Intraoral scanner (IOS)
Handheld 3D scanner used in the mouth; exports STL/PLY.
CAM
Computer-aided manufacturing software that turns the STL into milling or printing toolpaths.
Rx (prescription)
The dentist's order: teeth, restoration, material, shade, notes. AI intake fills CaseSetup from it.
Shade
Tooth colour code (e.g. A2) for the material.
exocad DentalCAD
Widely used desktop dental CAD; the reference workflow for this project.
.dentalProject / .constructionInfo
exocad's XML order file / the file written next to the STL for CAM (margin, axis, tooth). Our JSON sidecar plays the same role.
Dentbird
Cloud dental CAD with AI auto-design; the model for our AI-assist ambitions.
Golden case
A de-identified real case (scans plus the finished exocad crown) used for regression testing and tuning.

Geometry and graphics

Mesh / triangle soup
Surface made of triangles. STL stores each triangle separately, with no shared vertices (a "soup").
Vertex welding
Merging identical vertices so triangles share them. Required for normals, curvature and paths. Done by exact float bits.
Manifold / watertight
Every edge is shared by exactly two triangles, with consistent orientation: a closed solid that can be milled.
Signed volume
Volume computed from triangle orientation; positive means outward-facing normals.
Tri–tri intersection
Test for triangles crossing each other (self-intersection), e.g. the outer shell dipping below the intaglio.
BVH
Bounding volume hierarchy: a tree of boxes for fast ray casts and closest-point queries. Provided by three-mesh-bvh.
PCA
Principal component analysis: finds a point cloud's main directions. Used to guess "up" and "front" of an arch.
Normal
Direction perpendicular to the surface. Area-weighted vertex normals are used for shading and offsets.
Curvature (signed convex)
How sharply the surface bends, and whether outward (convex) or inward (concave). The margin follows convex edges.
Dijkstra / live-wire
Shortest-path search over the mesh graph. Live-wire shows the cheapest path to the cursor as you trace.
Geodesic
Shortest path along a surface (not through space).
Ray-cast envelope
The surface you'd see looking along a direction: rays keep the first hit. Used to block out undercuts.
Arc-length resampling
Placing points at equal distances along a curve, used to match loops point for point.
RBF deformation
Radial basis function warp: moves a mesh smoothly so chosen points hit targets (crown boundary → margin).
Displacement field
Per-vertex movement vectors. Smoothing these (not positions) keeps anatomy such as cusps.
ICP
Iterative closest point: aligns two shapes. Used for manual alignment refinement later.
Hausdorff distance
Largest distance from a point on one surface to the nearest point of another. Compares our crown with the exocad crown.
Matcap
"Material capture": shading from a small sphere image, independent of scene lights. Fast and consistent; generated procedurally here.
Render on demand
Drawing a frame only when something changed, which saves battery and GPU.
Orthographic vs perspective
Projection without / with depth foreshortening. Orthographic helps judge distances.
Colour map
Per-vertex values (distance, thickness) drawn as colours with a legend.
Units
Always millimetres. STL has no units, so implausible sizes trigger a warning.
WebGL
The browser's low-level API to the GPU. three.js wraps it.
Shader
A tiny program the GPU runs per vertex (where to draw) or per pixel (what colour). Materials are shaders plus settings.
Depth buffer
Per-pixel "distance of the nearest thing drawn so far", used to hide what's behind. It is why transparency needs careful draw order.
Raycast / picking
Firing an imaginary ray (e.g. from the mouse) and finding the first triangle it hits.
Winding
The order of a triangle's corners; it decides which side is the front.
Typed array
Float32Array, Uint32Array, …: compact blocks of raw numbers, used for all mesh data instead of JS objects.
sRGB vs linear colour
Screen-encoded vs maths-friendly colour values; scan colours are converted to linear when loaded.

Infrastructure

Caddy
A web server and reverse proxy (like nginx) with a short config file and automatic HTTPS. In our stack it serves the built web app and forwards /api/* to the API. See the primer.
Caddyfile
Caddy's config file: infra/Caddyfile.
Reverse proxy
A server that receives requests and forwards them to internal services; clients only see the proxy.
TLS termination
Where HTTPS is decrypted. In our deployment: Nginx Proxy Manager on the VM.
Nginx Proxy Manager (NPM)
The VM's web UI around nginx that owns the domain and Let's Encrypt certificates. It forwards to our Caddy (dcad-proxy:80) over the shared Docker network shared_net.
SPA fallback
Returning index.html for unknown paths so deep links into the single-page app work on reload.
Docker Compose
Runs several containers together from one file; service names (api, db) act as hostnames between them.
Named volume
Docker-managed persistent storage (pgdata, blobs) that survives rebuilds.
arm64 / aarch64
The CPU architecture of the OCI Ampere VM and Apple-silicon Macs. Images must be built for it.
Health check
A command Docker runs to know a container is ready (e.g. the API's /healthz).
Let's Encrypt
Free certificate authority; Caddy can obtain its certificates automatically.
Migration (database)
A versioned SQL change script, applied in order on start (apps/api/drizzle/).

Software architecture

DesignDocument
The single typed state of a case design: setup, scans, per-tooth frame, margin, axis, params, crown, step status.
Command
A typed, validated change to the document. The only way state changes, for the UI and AI alike.
Clinical command
A tooth-local command such as moveCrown {direction: 'mesial', mm}; also exposed to the LLM as a tool.
Snapshot undo
Undo by keeping immutable document versions (structural sharing keeps them cheap).
Step invalidation
Changing an earlier step marks later steps "stale" so they recompute.
Proposer
Anything that proposes a step's result: an algorithm, an ML model or an LLM. An async job with QA checks and a version id.
Orchestrator / QA gate
Runs proposers in sequence for one-click design; stops when a deterministic check fails.
ProposalEvent
A record of what was proposed and what the user accepted, with artifact references. Training data for future models.
Tool call
An LLM's structured request to run a named tool with JSON arguments.
Content-addressed
Identified by the hash (sha256) of its bytes, so identical data has an identical id everywhere.
Ports and adapters
Domain code depends on interfaces (ports); concrete technologies (adapters) plug in by config.
Web Worker / Comlink
A background browser thread / a library that makes calling worker functions look like normal async calls.
Transferable
A buffer moved (not copied) between threads.
zod / JSON Schema
TypeScript schema library / the standard JSON description of data shapes. zod generates JSON Schema for LLM tools.
Optimistic concurrency
Save only if nobody saved since you loaded (parent version check), otherwise 409.
Organisation (org)
A lab/tenant. Every row is scoped to one; each new user gets a personal org.
PUBLIC_URL / BASE_PATH
Where the app is served (e.g. https://dental.cognifuze.com) and the sub-path derived from it (empty at root).
