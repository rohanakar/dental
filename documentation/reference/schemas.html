Data contracts

Every schema shared by the web app, the API and future model services, generated from the zod definitions in packages/shared. If this page and the code disagree, the code wins — regenerate the page.

In short
  • 75 schemas in 9 source files; 10 LLM agent tools are generated from them.
  • zod v4 is the single source of truth: runtime validation in browser and API, JSON Schema for LLM tools, and later pydantic models for Python ML services.
  • All geometry is in millimetres; meshes are referenced by sha256 with explicit units and frame, never by face index.
  • Field tables show the input view: "Required: no" fields may be omitted (some then take a default).

Refinements that JSON Schema cannot express (for example the FDI quadrant/position rule) are enforced by zod at runtime but not shown here.
